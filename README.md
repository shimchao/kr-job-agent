# 한국형 구직 에이전트 (kr-job-agent)

공고를 붙여 넣거나 링크를 주면, **내 PC에서** 내 이력서와 비교해 지원할지 건너뛸지 알려 주고, 한국 양식에 맞는 자소서·경력기술서·맞춤 이력서를 만들어 주는 Claude Code 스킬 묶음입니다. **제출은 항상 사람이 누릅니다.**

> [career-ops](https://github.com/career-ops-hq/career-ops)(MIT, santifer)의 구조를 참고해 한국 채용 시장용으로 새로 만들었습니다. 코드는 가져오지 않았습니다.

## 할 수 있는 일
| 스킬 | 하는 일 |
|---|---|
| `/job-setup` | 이력서(`cv.md`)·희망 조건·검색어를 질문으로 채움 |
| `/job-scan` | 사람인·잡코리아 새 공고 목록을 모아 내 조건으로 1차로 추림. 사람인은 연봉 하한 필터(`--profile`) 사용 |
| `/job-batch` | 모은 공고를 연차·연봉·제목 키워드로 거르고 여러 건을 한꺼번에 평가(대기열·이어하기). 본문을 못 읽은 공고는 붙여 넣기 요청 |
| `/job-eval` | 공고 전체 평가(A~H): 마감 확인 · 요구사항별 매치 · 한국 채용 조건(포괄임금제·수습·고용 형태 등) · 급여 신뢰도 · 공고 신뢰도 · 점수와 지원/보류/건너뛰기 |
| `/job-apply` | 자기소개서(항목별·글자수 맞춤) · 경력기술서 · 포트폴리오 구성 · 지원 메일 — 결격 질문 점검과 초안 승인 후 저장 |
| `/job-resume` | 공고별 맞춤 이력서(마크다운·HTML·PDF) — 이력서에 있는 사실만 재배열 |
| `/job-research` | 회사 조사(6축) · 연락 메시지 초안 |
| `/job-interview` | 면접 준비 계획 · 모의면접(피드백) · 면접 후 복기 |
| `/job-offer` | 근로계약서·오퍼 조항별 읽기, 공고·면접 조건과의 차이, 노무사에게 물을 질문 |
| `/job-track` | 지원 현황 · 마감 임박 · 팔로업 시점과 메일 초안 · 거절·무응답 패턴 · 현황 대시보드(HTML) |

## 시작하기
1. 이 폴더를 내려받고 터미널에서 이 폴더로 이동해 `claude` 를 실행합니다(Claude Code 필요).
2. `/job-setup` 을 실행하고 질문에 답합니다. 이력서는 이 PC의 `cv.md` 에만 저장됩니다.
3. `/job-scan` 으로 공고를 모으거나, 평가하고 싶은 공고 링크·본문을 붙여 넣고 `/job-eval` 을 실행합니다.

필요한 것: Python 3.9 이상(표준 라이브러리만 사용, 설치할 패키지 없음. 개발자는 3.11·3.14 에서 테스트했고 3.9 는 문법 호환만 확인). PDF를 만들려면 Google Chrome. macOS 에서 검증했고 Windows 는 WSL 을 권장합니다(자세히는 `docs/START.md`).

**현직자라면** 개인 PC·개인 계정에서 쓰세요. 현재 회사의 내부 수치는 지원서에 쓰기 전에 매번 확인합니다(`docs/korea-signals.md` §9).

## 지키는 약속
- **이력서에 없는 사실은 쓰지 않습니다.** 공고에 맞추려고 경력·숫자를 만들어 내지 않습니다.
- **제출·전송을 대신하지 않습니다.** 초안까지만 만듭니다.
- **개인정보는 이 PC 밖으로 나가지 않습니다.** 이력서·희망 조건·`data/` 는 Git 에 올라가지 않습니다(`.gitignore`). 이력서 내용은 사용자가 쓰는 AI(Claude)에게만 전달됩니다.
- **법률 자문을 하지 않습니다.** 계약·근로조건은 확인할 질문으로 정리하고 판단은 노무사·고용노동부(1350)에게 넘깁니다.

## 공고 수집이 하는 일과 한계
- **사람인·잡코리아**의 공개 검색 목록만 읽습니다. 사이트의 robots.txt 가 막은 주소는 요청하지 않고, 요청 사이에 3초 이상 쉬며, 403·429 가 오면 바로 멈춥니다. 브라우저인 척하지 않고 이름표(User-Agent)에 도구 이름을 적습니다. 로그인·지원 경로는 건드리지 않습니다.
- **원티드**는 robots.txt 를 읽을 수 없어 자동 수집에서 제외했습니다. 공고 링크나 본문을 붙여 넣어 주세요.
- 상세 본문은 두 사이트 모두 본 화면과 다른 주소에 따로 있어, 도구가 그 주소(robots.txt 가 허용하는 경우만)까지 따라가 읽습니다. 그래도 상세 요강이 **이미지**로 올라온 공고는 글자를 읽지 못해 요약만 읽힙니다. 그때는 공고 상세 본문을 복사해 붙여 넣으세요(도구가 알려 줍니다).
- **공고 자동 수집은 사이트 약관·법적 분쟁 소지가 있을 수 있습니다. 이 도구를 만든 사람은 두 사이트의 이용약관 원문을 확인하지 못했습니다.** 사용 전에 각 사이트의 약관을 직접 확인하고 본인 책임으로 사용하세요. 부담되면 `scan.py` 를 쓰지 않고 공고를 직접 열어 본문을 붙여 넣는 방식만 써도 됩니다. 사이트가 막으면 이 도구도 멈춥니다.
- 사람인 연봉 필터는 엄격하지 않아 연봉 미표기·하한 미만 공고가 섞입니다(목록에 적힌 연봉으로 다시 거릅니다). 잡코리아는 연봉 필터가 없고 목록에 연차 숫자도 없어 제목의 「N년 이상」만 읽습니다.
- 잡코리아 목록은 화면 구조가 바뀌면 파싱이 깨질 수 있습니다(0건이면 알려 줍니다).

```
data/                      공고·보고서·지원서·면접 준비 (Git 제외)
scripts/                   scan.py · fetch_posting.py · liveness.py · tracker.py · batch.py · filters.py · dashboard.py · keyword_match.py · render_pdf.py · robots_guard.py · calc.py · extract_text.py
docs/                      korea-signals.md(한국 채용 점검표) · writing.md(글쓰기 규칙)
.claude/skills/            10개 스킬
tests/                     python3 -m unittest discover -s tests (스크립트) · tests/evals (실제 Claude 로 돌리는 평가 13건, Claude 사용량을 씁니다)
```

## 알려진 한계
- 사람인·잡코리아 외 사이트는 자동 수집하지 않습니다.
- 한국 연봉 시세는 웹 검색 결과에 의존하며, 출처가 없으면 「확인 불가」로 표시합니다.
- `keyword_match.py` 는 단어 빈도 기반의 참고용 점검입니다.
- 점수·판단은 권고입니다. 최종 결정은 사용자가 합니다.
