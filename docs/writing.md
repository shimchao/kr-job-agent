# 글쓰기 규칙 — 자소서·경력기술서·메일·메시지 모두 적용

1. **사실만.** `cv.md`·`article-digest.md` 에 있는 것만 쓴다. 문장마다 근거가 있어야 한다.
2. **결론을 먼저.** 항목의 첫 문장이 답이다. 배경 설명은 뒤에.
3. **한 일 + 결과.** "열정적으로", "최선을 다해", "성장하고 싶습니다" 대신 무엇을 했고 무엇이 달라졌는지(숫자·기간)를 쓴다.
4. **숫자는 출처가 있는 것만.** `cv.md` 에 없으면 「수치 확인 필요」로 남기고 사용자에게 묻는다. 반올림·추정으로 채우지 않는다.
5. **짧은 문장, 능동태.** 한 문장 한 가지 내용. "~할 수 있었습니다"보다 "~했습니다".
6. **빈 말 금지 목록**: 열정, 최선, 도전정신, 소통과 협업(근거 없이), 책임감 있는(근거 없이), 시너지, 글로벌 인재, 성실함(근거 없이).
7. **같은 구조 반복 금지.** 문단마다 "저는 ~했습니다"로 시작하지 않는다. 문장 길이를 섞는다.
8. **공고 단어는 맞춰 쓰되 베끼지 않는다.** 공고의 요구 → 내 경험으로 연결한다. 없는 경험의 단어를 넣지 않는다.
9. **회사 이야기는 확인된 것만.** 회사 소개·보도·공식 채용 페이지에서 확인한 사실만 쓰고, 출처를 근거표에 남긴다. 확인 못 하면 쓰지 않는다.
10. **글자수는 직접 센다.** 공백 포함/제외 기준을 먼저 확인하고, 파일로 저장해 `len()` 으로 잰다.
11. **말투 학습(선택).** 사용자가 쓴 글 3편 이상(`data/voice/`)을 주면 문장 길이·어미·자주 쓰는 표현을 뽑아 초안에 반영한다. 학습 결과도 사용자 글에 있던 표현만 쓴다.
