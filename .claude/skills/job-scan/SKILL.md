# job-scan — 새 공고 모으기

## 순서
1. `config/search.txt` 와 `config/profile.yml` 이 있는지 본다. 없으면 `/job-setup` 을 먼저 안내한다.
2. 실행한다 (기본: 검색어당 1페이지, 요청 간격 3초 이상):
   ```bash
   python3 scripts/scan.py
   ```
   검색어·페이지를 바꾸려면 `--keywords "A,B" --pages 2 --sites saramin` 을 쓴다. 저장 없이 보기만 하려면 `--dry`.
3. 출력의 「새 공고 N건」 표와 「못 가져온 것」을 읽는다.
4. `config/profile.yml` 의 직무·지역·고용 형태·경력과 **표에 적힌 정보만으로** 1차로 추린다.
   - 표에 없는 정보(연봉·업무 내용)로 판단하지 않는다. 판단이 안 되면 "상세 확인 필요"로 둔다.
   - 추린 후보 최대 10건을 `회사 · 제목 · 마감 · 조건 · 링크` 로 보여 주고, 왜 남겼는지 한 줄씩 적는다.
5. 후보 중 사용자가 고른 것을 `/job-eval` 로 넘긴다.

## 지키는 것
- **robots.txt 가 막은 주소는 `scan.py` 가 알아서 요청하지 않는다.** 「못 가져온 것」에 이유가 나오면 그대로 보고하고, 다른 방법으로 우회하지 않는다.
- 원티드는 robots.txt 를 읽을 수 없어 자동 스캔 대상이 아니다. 사용자가 원티드 공고 링크·본문을 붙여 넣으면 `/job-eval` 로 평가한다.
- 잡코리아 목록은 화면 구조가 자주 바뀐다. 공고가 0건으로 나오면 "구조가 바뀌었을 수 있음"이라고 보고하고 추측으로 채우지 않는다.
- 목록은 **제목·회사·마감·조건만** 담는다. 본문은 `/job-eval` 단계에서 읽는다.

## 보고 끝에 붙이는 것
확인 못 한 것(못 가져온 사이트·페이지, 목록에 없어서 판단 못 한 항목)을 최대 3개 적는다. 없으면 「없음」.
